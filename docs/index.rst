Simulation de trafic routier
============================

Documentation du projet de simulation de trafic routier en Python.

Le projet est organisé en trois paquets :

- ``models`` : véhicules, routes et réseau routier ;
- ``core`` : moteur de simulation et analyseur de statistiques ;
- ``out`` : affichage graphique et export des résultats.
